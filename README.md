### 🚀 Quick GitHub Pages Launch (3 Steps):
1. Create a repository on GitHub (e.g. `solviroenergy`).
2. Upload all files from this folder (`index.html`, `solviro_energy_product_catalogue.pdf`, `CNAME`, `.nojekyll`, `README.md`, and the `certificates/` folder) to the `main` branch.
3. In **Repository Settings > Pages**:
   - **Source:** Deploy from a branch
   - **Branch:** `main` / `/ (root)`
   - **Custom Domain:** `solviroenergy.in` (pre-filled by `CNAME`)
   - Check **Enforce HTTPS**

Your website will be live at **https://solviroenergy.in**!
